Stock Portfolio Tracker
A simple stock tracker that calculates total investment value based on manually defined (hardcoded) stock prices.
Goal
Build a simple stock tracker that calculates total investment based on manually defined stock prices.
Scope
User inputs stock names and quantity.
Uses a hardcoded dictionary to define stock prices (e.g., {"AAPL": 180, "TSLA": 250}).
Displays total investment value and optionally saves the result in a .txt or .csv file.
Key Concepts Used
dictionary
input/output
basic arithmetic
file handling (optional)
How to Run
Make sure you have Python 3 installed.
Clone this repository or download stock_tracker.py.
Run the program from your terminal
How to Use
The program displays the available stocks and their hardcoded prices.
Enter a stock symbol (e.g., AAPL) and the quantity you own.
Repeat for as many stocks as you like; type done when finished.
The program displays a summary of each holding's value and the total investment.
You'll be asked if you want to save the results to a .txt or .csv file.
